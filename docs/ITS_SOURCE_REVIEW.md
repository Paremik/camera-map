Открыта [публичная карта ITS Opole](https://its.mzd.opole.pl/mapa) в обычном Edge без авторизации. Включён слой Kamery. Скрипт страницы `https://its.mzd.opole.pl/mapa/static/js/app.9adecb11.js` содержит `fetchCameras`, обращающийся к `/api/cameras` на том же домене. В сетевых ответах страницы получен HTTP 200, Content-Type application/json. Не выполнялись подбор адресов, вход, извлечение закрытых данных или отключение TLS.

[Полученный endpoint](https://its.mzd.opole.pl/api/cameras) возвращает FeatureCollection из **159** точек с уникальными числовыми ID. Поля: properties.id, name, description, state, type, image; geometry.type = Point и coordinates = [долгота, широта]. Все типы в этом снимке — fixed. Значение state не интерпретируется как текущая доступность просмотра.

Диапазон опубликованных координат: широта 50.631417–50.7254, долгота 17.8116–17.9953. Например, ID 1 / S01_CCTV1 имеет описание `Niemodlińska - Wojska Polskiego - Hallera` и точку [17.896964, 50.663086]. Ни координаты, ни названия не вычислялись и не дополнялись догадками.

Снимок в `data/sources/its-opole-2026-09-03.json` содержит все исходные метаданные и может повторно пройти адаптер. SHA-256 исходного текста ответа до форматирования: `0aa45044a4bf553ad083bf8e24a4084210881c27b885d2d2443e0eae670f6419`.

Нормализованный каталог сохраняет идентификаторы, названия, подписи места, координаты и ссылку на источник. Для всех 159 записей heading, fov и rangeMeters равны null: этих параметров в ответе нет. Флаги независимой проверки координат и оптики остаются false. Кнопка просмотра открывает публичную карту издателя.
