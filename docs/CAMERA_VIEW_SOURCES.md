# Прямой просмотр камер — 2026-09-03

## Четыре вида ратуши

На [официальной странице города](https://www.opole.pl/opole-okiem-kamery) проверены подписи и адреса четырёх iframe. В обычном Edge каждый адрес плеера отвечает HTTP 200 и открывает отдельный вид:

| Запись                       | Плеер, опубликованный городом                |
| ---------------------------- | -------------------------------------------- |
| Aleja Gwiazd                 | https://player.webcamera.pl/opole_cam_8b53d4 |
| Wieża Piastowska / Amfiteatr | https://airmax.pl/ratuszopole1.html          |
| Katedra                      | https://airmax.pl/ratuszopole3.html          |
| ul. Św. Wojciecha / Na Górce | https://airmax.pl/ratuszopole2.html          |

`sourceUrl` по-прежнему ведёт на городскую страницу, `publicViewUrl` — на соответствующий плеер. Это обычная ссылка в новой вкладке, без извлечения потока. Кнопки издателя, включая запуск видео, сохраняются. HTTP 200 и наличие плеера не означают гарантированную работу трансляции.

[WebCamera публикует инструкцию для статического виджета](https://opole.webcamera.pl/umiesc), но она не подтверждает разрешение встраивать живой плеер в этот проект. Видеоплееры в приложение не встраиваются.

## Снимки ITS

Публичная [карта ITS](https://its.mzd.opole.pl/mapa) при выборе камеры получает `/api/cameras/<id>/images`. Этот путь присутствует в поле `image` сохранённого GeoJSON; скрипт самой карты `https://its.mzd.opole.pl/mapa/static/js/app.9adecb11.js` содержит `fetchCameraImagesData` и формирование изображения `/api/camera/image/<id>/<filename>`. Произвольные адреса камер не перебирались.

Для ID 1 получен HTTP 200 с массивом `images`: filename, addTime, size, mimeType и служебные поля. Проверен запрос из локального приложения с обычной проверкой TLS: сервер разрешает CORS. Последний снимок загружается с публичного домена ITS и виден в браузере. Это JPEG, не видеопоток.

Правила реализации:

- `snapshotSourceUrl` добавляется только при точном совпадении `image` с `/cameras/<id>/images`. Другой или отсутствующий путь оставляет обычную ссылку на карту ITS.
- Валидатор проверяет официальный источник, категорию ITS, числовой ID и точное соответствие endpoint этому ID. Пользовательские группы, OSM-точки и объекты не получают просмотр.
- Запросы выполняются только после нажатия «Снимок ITS» / «Открыть снимок камеры» и ручного обновления. Нет фонового опроса 159 камер, серверного прокси, сохранения снимков в каталоге или загрузки при открытии карты.
- Метаданные загружаются без учётных данных. Из ответа выбирается JPEG с максимальным корректным `addTime`; порядок массива не считается гарантированным. Имя файла проверяется и кодируется как один сегмент пути.
- Интерфейс показывает `addTime` с подписью «Время по ITS» в часовом поясе Europe/Warsaw. Это время, указанное издателем: оно может на несколько секунд отличаться от времени, напечатанного на изображении. Текущее время посетителя не подставляется.
- Предусмотрены пустой массив, ошибка запроса/картинки, ограничение ожидания 15 секунд, повторная попытка и ссылка на официальный портал. При закрытии окна запрос отменяется; изображение удаляется из DOM.

Контракт наблюдаемый, его стабильность не гарантирована ITS. Проверка конкретного снимка не подтверждает доступность всех остальных камер. Значение `state` в каталоге не объявляет камеру работающей.
