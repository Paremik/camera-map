# Импорт публичных камер ITS Opole

## Статус

Адаптер подготовлен, но реальный экспорт пока не добавлен. `data/its-cameras.json` содержит пустой массив. Отсутствие записей означает отсутствие проверенного импорта, а не отсутствие камер в городе.

Официальные источники:

- https://its.mzd.opole.pl/mapa — публичная карта со слоем камер.
- https://its.mzd.opole.pl/faq/ — описание портала.
- https://www.opole.pl/dla-turysty/opole-okiem-kamery — четыре вида с ратуши, уже включённые в начальный каталог.

## Порядок работы

1. Откройте официальный публичный слой камер. Зафиксируйте страницу источника и дату получения.
2. Используйте только координаты и идентификаторы, которые сам издатель отдаёт в публичном интерфейсе без авторизации. Сверьте условия повторного использования. Не угадывайте URL, потоки или пароли.
3. Преобразуйте документированный экспорт в приведённый ниже формат. Это наш контракт адаптера; он не заявляет формат или адрес API ITS.
4. Проверьте файл командой `pnpm import:its public-export.json`.
5. Сверьте названия и точки с исходной картой. Не добавляйте предполагаемые направления как проверенные.
6. Запустите с `--write`, просмотрите изменения, затем `pnpm typecheck && pnpm test && pnpm build`.

## Контракт

Обязательные поля верхнего уровня: `schemaVersion: 1`, `sourceUrl` (HTTPS, домен its.mzd.opole.pl), `retrievedAt` (реальная дата YYYY-MM-DD), `cameras` (1–10000 записей).

У каждой записи обязательны `id`, `name`, `street`, `lat`, `lng`. ID — стабильная строка из публичного источника. Если название улицы не дано, укажите правдивую подпись места из источника.

Опциональны `heading`, `fov`, `rangeMeters`, `publicViewUrl`. Если оптика не опубликована, пропустите поле или используйте null. Ссылку на просмотр добавляйте только когда издатель действительно предоставляет публичный просмотр.

Схематический пример с явными заглушками (преднамеренно **не импортируется** без реальных данных):

```json
{
  "schemaVersion": 1,
  "sourceUrl": "https://its.mzd.opole.pl/mapa",
  "retrievedAt": "YYYY-MM-DD",
  "cameras": [
    {
      "id": "PUBLIC_SOURCE_ID",
      "name": "NAME_FROM_PUBLIC_SOURCE",
      "street": "LOCATION_FROM_PUBLIC_SOURCE",
      "lat": null,
      "lng": null,
      "heading": null,
      "fov": null,
      "rangeMeters": null
    }
  ]
}
```

## Валидация и запись

- Размер входного файла до 10 MB; максимум 10000 записей.
- Координаты — числа: широта 50.5–50.85, долгота 17.7–18.15 (Opole с подходами). Переставленные широта/долгота отклоняются.
- Направление 0 ≤ heading < 360, от севера по часовой стрелке; угол 1–180°; дальность 1–5000 м.
- Дубликаты ID отклоняются. Итоговые ID имеют префикс `its:`, чтобы не конфликтовать с начальными видами.
- Ссылки — HTTPS-домены без встроенных логинов/паролей. Скрипт не запрашивает эти адреса.
- Все импортированные записи получают `verified: false` и `opticsVerified: false`. Сам факт импорта не подтверждает точность.
- Без `--write` файлы не меняются. С ним весь набор проходит проверку, затем временный файл атомарно заменяет `data/its-cameras.json`. Пустой импорт отклоняется.
- Начальные виды `data/cameras.ts` не заменяются. Итоговое объединение повторно проверяется на границе репозитория данных.

Для ручного подтверждения обновите соответствующие поля и ссылку на подтверждающий публичный источник в нормализованных данных; сохраните объяснение в коммите. Автоматический повторный импорт сбрасывает ручную верификацию: перед ним всегда проверяйте diff. Для будущей синхронизации вынесите ручные подтверждения в отдельную таблицу.

## Будущая интеграция

После подтверждения публичного API добавьте отдельный адаптер его формата. Сохраняйте исходный ID, дату и доказательства происхождения; используйте тот же валидатор. Базу данных подключайте через `getCameras()`. Для существенно больших каталогов добавьте загрузку по области карты и серверную пагинацию; сейчас карта кластеризует точки, а список показывает по 50 записей.
