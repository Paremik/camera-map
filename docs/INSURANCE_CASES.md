# Поиск источников для страхового случая

Раздел «Страховой случай» помогает подготовить первичный запрос после ДТП или повреждения имущества. Пользователь отмечает место на карте, задаёт радиус, дату/время и необязательный номер дела. Все эти поля живут только в текущей вкладке, пока она открыта.

Результат показывает записи из опубликованного каталога, расстояние до места происшествия, публичный источник и шаблон просьбы о сохранении записи. JSON-экспорт сохраняет координаты, дату, радиус, источник и уровень неопределённости для ручной проверки. «Печать / PDF» использует штатную печать браузера.

Это не поиск видеозаписей и не доступ к системам наблюдения. Карта не доказывает, что камера видела событие, работала в тот момент, хранит запись или может её передать. Положение, оптика и принадлежность части записей не подтверждены. История доступности и сроки хранения записей в каталоге отсутствуют. Связь с владельцем ведётся пользователем через публичный источник или официальный канал владельца; приложение не отправляет сообщения и не загружает персональные данные.

Передавать или публиковать видеозаписи можно только с учётом применимого права и требований к защите персональных данных. Для Польши справочные материалы по видеонаблюдению публикует [UODO](https://uodo.gov.pl/pl/701/4470).
