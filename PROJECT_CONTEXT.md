# Контекст camera-map

Последнее обновление: 2026-09-02. Репозиторий: Paremik/camera-map.

## Цель пользователя

Продолжать разработку в этой же задаче Codex: интерактивная карта публичных камер Opole, выбор камер, карточки, направления/секторы, 2D/3D и последующий массовый импорт ITS. Не требовать ручного переноса промптов. Использовать только публичные данные.

## Исходное состояние

Начальный коммит: 1e28d09. Небольшой Next.js-прототип с четырьмя видами ратуши. Все маркеры перекрывались на одной точке. Сборку ломал устаревший MapLibre-параметр antialias. Отсутствовали lockfile, фильтры, переключатель 2D/3D и обработка ошибок карты.

## Текущее решение

- MapLibre + OSM, без обязательных ключей. Исправлен параметр canvasContextAttributes.
- Исправлена ошибочная исходная точка ратуши: теперь 50.66855, 17.92240 внутри публичного контура OSM way 207031541. Это приблизительное положение здания, не подтверждённые места крепления камер; positionSourceUrl хранит источник.
- Отдельные компоненты каталога, карты и карточки. MapLibre загружается только в браузере.
- Поиск с польской диакритикой, фильтры, корректное пустое состояние, кластеризация и выбор совпадающих координат.
- Карточка, иллюстративные сектора и направление, переключение 2D/наклонённой перспективы.
- Адаптивный мобильный каталог; кнопка просмотра закреплена вне прокручиваемой части карточки.
- Типизированный репозиторий и CLI импорта с dry run, строгой валидацией и атомарной заменой данных.
- Повторяемая установка, typecheck, 12 тестов, production build и GitHub Actions.

## Ограничения данных

В каталоге только четыре исходных публичных вида, описанных городом. Их точные координаты и оптика НЕ подтверждены; verified и opticsVerified остаются false. Ссылки ведут на официальную страницу, доступность видео не проверяется автоматически. Датасет ITS пуст; адрес или формат публичного API ещё не подтверждён. Не выдавать эти четыре записи за импорт реальных ITS-точек.

3D означает наклон карты без объёмных зданий. Нет учёта препятствий или точной геометрии обзора.

## Следующий содержательный шаг

Проверить документированный публичный экспорт ITS Opole, условия использования и координаты. Подключить его через docs/ITS_IMPORT.md. Точные координаты, поворот, FOV и дальность верифицировать отдельно; не придумывать данные.

## Рабочий процесс

Прочитать README.md, CODEX_PROMPT.md, этот файл и инструкции AGENTS.md. Сохранять рабочую функциональность, проверять источник каждой новой записи. Перед коммитом выполнить pnpm typecheck, pnpm test, pnpm build; проверить карту в браузере после изменений интерфейса. Обновлять этот контекст при изменении решения.
